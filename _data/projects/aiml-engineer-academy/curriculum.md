# AI/ML Engineer Academy — curriculum map

The curriculum is the production AI engineer skill stack, not a list of model names.

| Module | Stack |
| --- | --- |
| **1. Foundations** | Python, Docker, git, APIs; data prep, features, classical ML, evals |
| **2. LLM architectures** | Transformers / Flash Attention, DPO / RLHF / GRPO, MoE, LoRA / QLoRA, quantization, diffusion, RAG vs fine-tune |
| **3. Orchestration** | RAG, MCP, DSPy, CoT / ReAct, LangGraph / PydanticAI |
| **4. System design** | Problem / scope / design / optimize; example systems; latency and cost |
| **5. Deployment** | Cloud (Azure, AWS, GCP), evaluation, productionization |

## Design rules

- **Evidence over attendance.** Labs produce pytest output. The UI cannot mark a module complete without that confirmation.
- **Survey vs proved.** The atlas is allowed to show topics that are lecture-only. The applet is not allowed to imply those were lab-proved.
- **Mentor is optional.** Same pattern as other SYSTEMS work: the model sits on the workflow; the workflow still exists if the key is missing.

This maps to the longer curriculum document used to design the academy; the GitHub labs are the executable slice.
