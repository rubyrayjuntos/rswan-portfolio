# Canon Forge — identity canon

Generative production fails when every frame is a new negotiation with the model. Canon Forge’s rule matches the rest of this catalog: **the model does not own state**.

## Identity kernel

The approved headshot is the identity kernel. Wardrobe and expression sheets are derived assets, not a second character. `buildCharacterIdentityBlock` writes a mandatory lock (skull, eye spacing, markers, wardrobe DNA). When the provider accepts it, the still is also sent as a reference or init image.

If a generated frame disagrees with the kernel, it is not auto-canon. The UI can mark a take approved or rejected. That is a human gate, not a biometric matcher.

## Set as a second kernel

Rooms drift the same way faces do. Landmarks, forbidden changes, and a lighting lock are the set’s equivalent of the headshot. A library that grows a window between the wide and the close-up is a failed take even if the actor is perfect.

## Shot grammar

Compositor fields (master / medium / close / insert, lens presets, camera angle) are production language. The model is asked to render a specified shot of specified assets.

## Honest boundary

This is a working studio tool with real providers behind an Express proxy. It is not InstantID. It is not tenant-isolated SaaS. The GitHub README still carries AI Studio scaffolding. The product substance is the four forges, the profile types, the identity-lock module, and the multi-provider generate path.
