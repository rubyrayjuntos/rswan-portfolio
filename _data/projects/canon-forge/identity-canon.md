# Canon Forge — identity canon

Generative production fails when every frame is a new negotiation with the model. Canon Forge’s rule is the same as the rest of the AI work in this catalog: **the model does not own state**.

## Identity kernel

The approved headshot is the identity kernel. Wardrobe, expression, and body sheets are derived assets, not a second character. If a generated frame disagrees with the kernel, it is not canon — it is a rejected take.

## Set as a second kernel

Rooms drift the same way faces do. Landmarks, forbidden changes, and a lighting lock are the set’s equivalent of the headshot. A library that grows a window between the wide and the close-up is a failed take, even if the actor is perfect.

## Shot grammar

Compositor fields (master / medium / close / insert, lens presets, camera angle) are the production language. The model is asked to render a specified shot of specified assets, not to invent a still it thinks looks cinematic.

## Honest boundary

This is a working studio tool with a real model behind it. It is not a deployed SaaS with tenant isolation. The GitHub README still carries AI Studio scaffolding. The product substance is the four forges and the profile types — that is what this case study is pinning.
