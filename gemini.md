# Custom Instructions for Gemini CLI Agent

## File Backup Policy

Before making *any* modifications to an existing file, create a backup of that file. The backup file should be named by appending the current date and time (in `YYYYMMDD_HHMMSS` format) to the original filename, before the file extension.

**Example:**
If modifying `index.html` on August 14, 2025, at 10:30:00 AM, the backup should be `index.html.bak_20250814_103000`.

This policy ensures that all original file states are preserved before changes are applied, allowing for easy reversion if necessary.
